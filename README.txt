Google Search Console verification patch

Upload these three files to the ROOT of the GitHub repository (same level as style.css).
- index.html  : includes Google site verification meta tag
- sitemap.xml : sitemap for the public site
- robots.txt  : allows crawling and points to sitemap.xml

After GitHub Pages deploys, return to Google Search Console and click Verify.
Then submit sitemap.xml under Sitemaps.
