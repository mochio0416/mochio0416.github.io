# Photo replacement guide

The current site is complete without photographs. When suitable photographs are selected, recommended placements are:

1. **Top / hero** — greenhouse or strawberry canopy, wide landscape crop.
2. **High-yield research** — strawberry plant/canopy and root image.
3. **Controlled environment** — greenhouse/environment-control scene.
4. **Postharvest** — fruit/storage/treatment scene.
5. **Sensing** — measurement or hyperspectral/3D sensing scene.

Use WebP or JPEG, ideally 1600–2200 px on the long edge. Avoid stretching; crop with CSS `object-fit: cover`.
For AI-generated conceptual images, retain a visible caption stating that the image is a conceptual illustration created with ChatGPT and is not experimental data or an experimental photograph.
